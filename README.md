# City Explorer

Mini-site de prezentare a unor destinații turistice, realizat în cadrul disciplinei Tehnologii Web.
Macheta statică include o listă de destinații, un formular pentru planificarea unei excursii și recomandări de călătorie.
Pagina este construită cu HTML semantic și CSS (Flexbox și Grid) și se adaptează la ecrane mici.
